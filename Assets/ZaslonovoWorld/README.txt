ЗАСЛОНОВО — ПРОГУЛОЧНАЯ СЦЕНА

Откройте Assets/Scenes/Zaslonovo_Camp.unity и нажмите Play.
Сцена добавлена первой в Build Settings.

WASD — ходьба; мышь — обзор; Shift — бег; Space — прыжок.
Esc освобождает курсор. Щелчок мышью снова захватывает его.
R возвращает игрока к исходной точке.

Основные корпуса используют URP prefab. Импорт FBX по умолчанию также
переназначен на соответствующие URP-материалы. Варианты BuiltIn сохранены
как исходные альтернативы и не используются в этой сцене.

У сосен три LOD, общие меши и материалы с GPU instancing; стволы имеют
коллизии. Дорожки и площадки проходимы, входы сохраняют исходные коллизии.
Рельеф — Unity Terrain с двумя PBR-слоями. Полных интерьеров корпусов нет.

Контуры взяты из OpenStreetMap; описание сопоставлений и ограничений точности
находится в References/Research.txt. Это реконструкция для прогулки,
а не точный геодезический план. Подтверждённый объект — бассейн; назначения
остальных четырёх контуров сопоставлены предварительно.

Runtime/CampFirstPersonController.cs — контроллер на новом Input System.
Editor/CampSceneBuilder.cs — воспроизводимая сборка сцены.
Tools > Zaslonovo > Validate camp scene — проверка ссылок и основной конфигурации.
Tools > Zaslonovo > Build camp scene — пересборка; заменяет сгенерированную сцену.
Перед пересборкой сохраните ручные изменения в отдельную сцену.
Лицензии внешних текстур и карт — References/ThirdPartyNotices.txt.
