в метры относительно 55.062494 N, 82.829240 E. Unity +X — восток, +Z — север.

Схема — иллюстрация, а не геодезический генплан.

Контуры, сопоставленные с моделями:
538191838 — большой корпус с крыльями, использован для центра детского творчества.
243048722 — небольшой корпус у бассейна, использован для корпуса с наружной лестницей.
243048721 — длинный жилой корпус, использован для бежевого корпуса с балконом.
538191833 — северо-восточный корпус, использован для одноэтажного оранжевого корпуса.
538191831 — здание, явно помеченное в OSM как swimming / sports_centre; бассейн.

Только назначение бассейна подтверждено тегами карты. Четыре остальных
сопоставления сделаны по форме и размерам и остаются предварительными.
Направления входов ориентированы к внутренним аллеям; фотографиями со всех
сторон это не подтверждено. Масштаб ранее построенных моделей не изменялся.

Часть прогулочных аллей дополнена по иллюстрированной схеме для связности
игровой территории. Деревья, цветники, скамейки, указатели и парковый свет
воссоздают характер фотографий; их конкретные точки не являются обмерами.
Невидимые / не смоделированные здания лагеря не заменялись случайными копиями.
