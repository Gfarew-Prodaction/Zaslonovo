ЗАСЛОНОВО — ТРИ ЗДАНИЯ ДЛЯ UNITY

Beige — бежевый двухэтажный корпус с гранёным выступом и балконом.
Mural — оранжевый одноэтажный корпус с персонажами на фасаде.
Pool — бассейн с длинной арочной крышей и круглым окном.

Импортируйте Zaslonovo-Three-Buildings.unitypackage. Для каждого здания
выберите prefab с суффиксом BuiltIn или URP в соответствующей папке.
URP-вариант требует установленного Universal Render Pipeline.
Проверено в Unity 6000.6.8f1, URP 17.6.0, а также в отдельном Built-in проекте.

Единицы: 1 = 1 метр. Pivot — на уровне земли. Главный фасад смотрит по +Z
в готовом Unity prefab. FBX экспортирован с Y-up. Модель внутри prefab
имеет необходимый поворот; используйте корневой объект prefab.

LODGroup автоматически переключает три уровня:
Beige: 379675 / 107203 / 56304 треугольников.
Mural: 288140 / 84188 / 32449 треугольников.
Pool: 475969 / 139906 / 49036 треугольников.
Лимит 500000 треугольников соблюдён для максимального уровня каждого здания.
Сумма всех трёх уровней в файлах больше числа одновременно отображаемых полигонов.

Коллизии — простые BoxCollider, независимо от визуальных мешей.
Фасадные панели, сайдинг, профили кровли, рамы, ручки, ограждения,
водостоки и входные узлы выполнены геометрией. Карты PBR 2048 px,
стекло прозрачное; за окнами есть неглубокие ниши и шторы.
Полноценных внутренних помещений нет.

Это реконструкция по фото, без обмеров. Размеры приблизительные.
Не показанные на референсах задние и боковые части восстановлены
по архитектуре здания; их точность не подтверждена фотографиями.
Назначение одноэтажного корпуса по доступным фото не установлено.
