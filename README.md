# Заслоново

Unity-проект для прогулки по реконструированной территории лагеря «Заслоново».
Пять зданий, сосновый лес, дорожки, освещение и управление от первого лица.
Материалы настроены для Universal Render Pipeline (URP).

![Территория лагеря](CampPreviews/FirstPerson.png)

## Запуск

1. Установите Unity **6000.6.8f1** через Unity Hub и [Git LFS](https://git-lfs.com/).
2. Склонируйте репозиторий вместе с моделями и текстурами:

   ```sh
   git lfs install
   git clone https://github.com/Gfarew-Prodaction/Zaslonovo.git
   cd Zaslonovo
   git lfs pull
   ```

3. Добавьте папку проекта в Unity Hub и дождитесь импорта ресурсов.
4. Откройте `Assets/Scenes/Zaslonovo_Camp.unity` и нажмите Play.

Управление: **WASD** — ходьба, **мышь** — обзор, **Shift** — бег,
**Space** — прыжок, **Esc** — освободить курсор, **R** — вернуться к точке появления.

## Модели

- `Assets/Zaslonovo` — центр детского творчества.
- `Assets/Zaslonovo_Corpus` — двухэтажный корпус с наружными лестницами.
- `Assets/Zaslonovo_Three` — бежевый корпус, оранжевый корпус и бассейн.
- `Assets/ZaslonovoWorld` — территория, окружение и контроллер игрока.

Здания реконструированы по фотографиям. Размеры и невидимые на фотографиях
фасады приблизительны; полные интерьеры не моделировались.
Максимальная детализация каждого здания — менее 500 000 треугольников.

Модели и текстуры хранятся в Git LFS. Кэш Unity, локальные настройки и сборки
не входят в репозиторий и создаются при открытии проекта.
